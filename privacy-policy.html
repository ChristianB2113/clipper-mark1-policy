Clipper Mark 1 Privacy Policy

Effective date: 2026-07-23

This Privacy Policy explains how Clipper Mark 1 handles user data.

1) Data We Handle

  • Website content selected by you, or page text extracted when you run the extension.
  • Web history-related data used by optional history features (page URL, page title, timestamp).
  • Settings and preferences (extraction mode, templates, domain rules, and privacy toggles).

2) How Data Is Used

  • To generate AI-ready text output at your request.
  • To provide optional local history and preference features.
  • To apply user-selected redaction and formatting options.

3) Storage and Retention

  • Data is stored locally in your browser using Chrome extension local storage.
  • No cloud backend is required for core extension functionality.
  • You can disable history and adjust retention in extension settings.

4) Data Sharing and Sale

  • Clipper Mark 1 does not sell personal data.
  • Clipper Mark 1 does not transfer user data to third parties for unrelated advertising.
  • If you use external checkout links, payment providers process checkout under their own privacy terms.

5) Why Permissions Are Used

  • activeTab: access current tab content only when you run the extension.
  • scripting: run extraction logic on the active page.
  • clipboardWrite: copy generated output to your clipboard.
  • storage: save local settings and optional history.

6) Security

  • The extension is designed to minimize exposure by using local storage for core features.
  • You are responsible for browser and device security controls in your environment.

7) Children's Privacy

  • Clipper Mark 1 is not directed to children under 13.

8) Policy Changes

  • This Privacy Policy may be updated over time.
  • Updates will be posted on this page with a revised effective date.

9) Contact

  • For privacy questions, use the support contact listed on the Chrome Web Store listing for Clipper Mark 1.
